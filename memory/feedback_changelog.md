name: Changelog operativo
description: Aggiornare CHANGELOG.md alla fine di ogni sessione con modifiche significative
type: feedback
---

Alla fine di ogni sessione di lavoro che produce modifiche (nuovi tool, workflow, config, servizi), proporre l'aggiornamento di `CHANGELOG.md` seguendo la SOP in `workflows/changelog.md`.

**Why:** L'utente vuole un log persistente di cosa facciamo sessione per sessione, con motivazioni e file toccati. Serve come documentazione operativa.

**How to apply:** Prima di chiudere una sessione con modifiche, leggere `CHANGELOG.md`, aggiungere entry con data, cosa, perché, file toccati, azioni manuali rimanenti. Formato in `workflows/changelog.md`.
